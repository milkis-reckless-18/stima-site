# Corrected Prova images

Each file here replaces one of Marianna's embedded images on import. The file name is the name the
import script gives the original (the first 12 hex digits of the SHA-256 of its bytes plus the
extension), so a fix applies only while she ships that exact image; if she replaces the image, the
fix is ignored and the new image goes out as she made it.
